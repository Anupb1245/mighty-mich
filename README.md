# Mighty-Mich

**One Dashboard. Every Model. Infinite Accounts. Zero Limits.**

Unified AI command center: route every AI tool through one endpoint with
multi-account pools, automatic failover, load balancing, and unified
conversation context across 290 providers.

- Dashboard: http://localhost:21128
- OpenAI-compatible API: http://localhost:21128/v1

## Run

```bash
npm install
npm run dev
```

Default login password: `CHANGEME` (change immediately in the dashboard).
